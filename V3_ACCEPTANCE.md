## How to reproduce the source audit

In the version identified as the baseline, inspect terminal.py for the displayed version, paper_engine.py for MAX_DEBIT, DAILY_STOP, PREMIUM_STOP and sizing, decision_engine.py and monitor_engine.py for entry and lifecycle gates, option_quotes.py for the two-sided quote check, research_snapshot.py for bounded mirror limits, and adaptive_exits.py for the existing comparison. The historical PACKAGE_MANIFEST.json predates V2.9.0. The files used to assemble this release are pinned by Git and listed with a SHA-256 inventory in the outer release.

V3 modules use journal kind prefixes to keep research scans out of simulated order flows. Historic candidate rows and old database contents need no destructive migration. Keep live-market testing separate from automated regression tests. Give PostgreSQL integration tests an empty disposable database via their dedicated TEST_PG_DSN settings. Never point those tests at the production journal.
